# 💾 Simple Image Save (ComfyUI)

Простой кастомный нод для ComfyUI — сохранение изображений в заданную папку.
Минимум настроек: только то, что действительно нужно.

## Возможности

- 📁 Сохранение в **любой путь** (абсолютный, например `D:\AI\renders`, или подпапку от `output/`).
- 📅 Опциональная папка по текущей дате (`YYYY-MM-DD`) + подпапка `Processed`.
- 🔢 Имя файла: `prefix_1 + prefix_2` с разделителем и **счётчиком** (`0001, 0002…`). Счётчик сканирует папку — после перезапуска ComfyUI нумерация не сбрасывается.
- ⏱ Альтернатива счётчику: суффикс времени `HHMMSS`.
- 🖼 Форматы: **PNG / JPG / WebP** (качество для lossy).
- 📦 Embed workflow в метаданные PNG + сохранение соседнего `.json` с рабочим процессом.
- 🔌 Выходы: `IMAGE`, `saved_path` (абсолютный путь первой картинки), `filename_text` (имя без расширения) — удобно для последующих нод.

## Установка

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/VeniaminPetrov/ComfyUI-ImageSave.git
# зависимости уже есть в python_embeded, но при необходимости:
pip install -r ComfyUI-ImageSave/requirements.txt
```

Перезапустите ComfyUI. Нод доступен в категории **Utility → Image** как `💾 Simple Image Save`.

Через ComfyUI Manager: добавьте репозиторий по URL и установите.

## Использование

1. Подключите `images` (любой IMAGE-выход).
2. Укажите `output_path`:
   - абсолютный: `D:\AI\renders\портреты` → сохранится туда;
   - относительный: `портреты` → сохранится в `ComfyUI/output/портреты`;
   - пусто → корневая `output/`.
3. Включите 📅 папку по дате / подпапку Processed при желании.
4. Задайте префиксы (пустые префиксы = имя только из счётчика).
5. Выберете формат и качество, запустите очередь.

> ⚠️ Превью в UI ComfyUI отображается только для файлов внутри `output/` — это ограничение самого сервера ComfyUI. Файлы вне `output/` сохраняются на диск нормально, просто превью в ноду не подтянется.

## Намеренные упрощения

- 2 префикса имени (дата — отдельной папкой, не парсингом в именах)
- без оптимизации PNG внешними бинарниками — чистый Pillow
- один общий слайдер качества для JPG/WebP
